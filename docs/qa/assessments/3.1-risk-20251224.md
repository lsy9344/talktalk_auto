# Risk Profile - Story 3.1 (2025-12-24)

## 전체 판단

- **리스크 수준**: 낮음(Low)
- 이유: 로직이 단순하고(리스트 합치기/중복 제거), 예외 상황도 `[]` 기본값으로 안전하게 처리하며, 유닛 테스트가 충분합니다.

## 주요 리스크와 확인 결과

1. **DATA-001: COMMON_DOC_IDS 설정 누락/오류로 공통 문서가 빠질 위험**
   - 상황: GlobalMode 테이블에 `config_key="COMMON_DOC_IDS"` 아이템이 없거나 `doc_ids` 타입이 리스트가 아닐 수 있습니다.
   - 영향: 시스템이 죽진 않지만, 공통 문서가 빠져 RAG 답변 품질이 떨어질 수 있습니다.
   - 확인/조치: `CommonDocIdsRepository.get_common_doc_ids()`가 아이템 없음/타입 이상/ClientError에서도 `[]`를 반환하도록 구현 + 유닛 테스트로 확인했습니다.
   - 남은 할 일(운영): 배포 전/채널 오픈 전, COMMON_DOC_IDS가 들어있는지 한 번 확인하는 체크가 있으면 더 안전합니다.

2. **TECH-001: common_doc_enabled 타입이 bool이 아닐 때 오동작 가능**
   - 상황: `build_final_doc_list()`는 `common_doc_enabled`를 그대로 `if`에 사용합니다(파이썬은 문자열 `"false"`도 True로 봅니다).
   - 영향: 공통 문서가 원치 않게 포함될 수 있습니다.
   - 확인: DynamoDB에서는 보통 bool 타입을 쓰기 때문에 실제로는 가능성이 낮습니다.
   - 제안(선택): bool이 아니면 기본값(True)로 처리하거나, 명확히 True/False만 허용하는 방어 코드를 추가할 수 있습니다.
