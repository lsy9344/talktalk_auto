## Detailed Risk Register

### REL-001: 메타데이터 값에 ` | `가 들어가면, 나중에 파싱할 때 헷갈릴 수 있음

- **Score: 2 (Low)**
- **Why it matters**: 지금은 “문자열”만 만들지만, 나중에 citations 같은 기능에서 헤더를 다시 읽어야 할 수 있습니다. 그때 ` | `로 단순 split 하면 값이 깨질 수 있습니다.
- **Mitigation**:
  - 후속 스토리에서 `key=value` 기반으로 읽거나, 값에 대한 escape 규칙을 정합니다.
  - (이미 좋음) 현재 테스트에 `doc_title`에 `|`가 들어가는 케이스가 있습니다.
- **Testing Focus**:
  - `doc_title`/`section_path`에 `|`가 들어가도 포맷이 깨지지 않는지 확인
  - 후속 파서가 생기면 “round-trip(만들고→읽기)” 테스트 추가

### REL-002: 청크 텍스트에 `<KB>`/`</KB>` 같은 문자열이 있으면, 사람이 읽기 어렵

- **Score: 2 (Low)**
- **Why it matters**: Google Docs 원문에 이런 문자열이 들어가면, `<KB>...</KB>` 블록 경계가 눈으로 보기 헷갈릴 수 있습니다.
- **Mitigation**:
  - 후속 스토리에서 태그를 더 안전한 토큰으로 바꾸거나, 텍스트 escape 규칙을 정합니다.
- **Testing Focus**:
  - 청크 텍스트에 `</KB>`가 들어가도 함수가 깨지지 않는지(문자열 생성 자체는 문제 없음) 테스트로 확인
