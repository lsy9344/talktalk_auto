## Detailed Risk Register

### SEC-001: User Prompt에 개인정보(user_id/question_raw) 포함

- **Score: 2 (Low)**
- **Why it matters**: LLM 요청에 개인정보가 들어가면, 로그/모니터링/알림에 같이 남을 수 있습니다.
- **Mitigation**:
  - LLM 호출 단계에서 prompt 내용을 로그로 남기지 않기
  - 꼭 필요하면 user_id/질문 텍스트를 마스킹해서 남기기
- **Testing Focus**:
  - 통합 테스트/리뷰에서 “raw question_raw/user_id 로그 출력 없음” 확인

### REL-001: question_raw에 `{{...}}`가 있을 때 내용이 바뀔 수 있음

- **Score: 2 (Low)**
- **Why it matters**: 고객 질문은 “원문 그대로”가 기본인데, 템플릿 치환이 질문 안까지 바꾸면 원문이 훼손됩니다.
- **Mitigation**:
  - 템플릿 문자열에서만 `{{...}}`를 치환하도록 구현(정규식 1회 치환)
  - `question_raw`에 `{{...}}`가 있어도 그대로 유지되는 테스트 추가(회귀 방지)
- **Testing Focus**:
  - `question_raw`에 `{{from}}`/`{{kb_chunks}}`가 포함된 케이스 테스트

- 통합(다음 스토리): Worker에서 LLM 호출 시 prompt/PII가 로그에 남지 않는지 확인
