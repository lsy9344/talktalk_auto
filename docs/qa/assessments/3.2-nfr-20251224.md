# NFR Assessment - Story 3.2 (2025-12-24)

## Security (보안)

- 상태: PASS
- 확인:
  - 시크릿은 `talktalk_shared/utils/secrets.py`를 통해 SSM Parameter Store(SecureString)에서 가져옵니다.
  - 로그에 시크릿 값/문서 본문이 찍히지 않습니다(문서 텍스트는 길이만 기록).
  - DynamoDB/S3 접근은 SAM 정책으로 필요한 범위만 허용합니다(테이블/버킷 제한).

## Performance (성능)

- 상태: PASS
- 확인:
  - 변경 감지(revision_id)로 “안 바뀐 문서”는 스킵해서 비용을 줄입니다.
  - 문서 수가 많아지면 900초 안에 끝나는지/임베딩 비용이 어떤지 모니터링이 필요합니다(운영 체크).

## Reliability (신뢰성)

- 상태: PASS
- 확인:
  - 문서 1개가 실패해도 전체가 멈추지 않게 `try/except`로 계속 진행합니다.
  - Circuit Breaker로 외부 API 장애가 길게 이어질 때 연쇄 실패를 줄입니다.
  - DynamoDB Scan 페이지네이션을 처리해, 채널이 많아져도 누락 위험을 줄였습니다.

## Maintainability (유지보수)

- 상태: PASS
- 확인:
  - Repository/Client/Chunker로 역할을 나눠서 코드가 이해하기 쉽습니다.
  - `python3 -m ruff check .`, `python3 -m mypy src`, `python3 -m pytest -q`로 기본 품질을 확인했습니다.
