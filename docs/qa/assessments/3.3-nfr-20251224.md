# NFR Assessment - Story 3.3 (2025-12-24)

## Security (보안)

- 상태: PASS
- 확인:
  - 문서 본문(청크 텍스트)을 로그로 남기지 않고, 길이/개수 중심으로 기록합니다.
  - 시크릿은 SSM Parameter Store(SecureString) 사용 흐름을 따릅니다.

## Performance (성능)

- 상태: PASS
- 확인:
  - 400~800 tokens 근처로 청크를 맞춰 임베딩 비용과 검색 품질 균형을 노립니다(근사 기준).
  - 운영에서 문서 길이/청크 수 증가 시 비용 모니터링을 권장합니다.

## Reliability (신뢰성)

- 상태: PASS
- 확인:
  - 헤딩이 없거나 섹션 텍스트가 없으면 문서 전체 1개 섹션으로 fallback 합니다.
  - `langchain_text_splitters`가 없으면 fallback chunking으로 동작합니다.

## Maintainability (유지보수)

- 상태: PASS
- 확인:
  - Chunk/Section 모델이 분리되어 있고, 유닛/통합 테스트가 있습니다.
  - `python3 -m pytest -q`, `python3 -m ruff check .`, `python3 -m mypy src`가 통과합니다.
