## Detailed Risk Register

### DOC-001: PRD 샤드 vs epic 문서의 따옴표 표기 불일치

- **Score: 2 (Low)**
- **Why it matters**: “그대로 복사” 기준이 애매해져, 나중에 프롬프트 검증/리뷰에서 혼란이 생길 수 있습니다.
- **Mitigation**:
  - 프롬프트 원문 기준 문서를 하나로 정하기(예: PRD 샤드)
  - 다른 문서에는 링크만 두고, 텍스트 복사본은 최소화하기
- **Testing Focus**:
  - 원문(PRD)과 코드 상수 텍스트가 정확히 같은지 비교 테스트 유지

### REL-001: 프롬프트 문구가 실수로 바뀌어 스키마가 깨질 위험

- **Score: 2 (Low)**
- **Why it matters**: LLM 출력은 이후 단계에서 JSON 파싱/검증을 하므로, 프롬프트가 바뀌면 실패/오동작이 날 수 있습니다.
- **Mitigation**:
  - `DEVELOPER_PROMPT` 변경 시 유닛 테스트가 실패하도록 유지
  - 코드 리뷰에서 “프롬프트 변경”을 따로 확인하기
- **Testing Focus**:
  - `DEVELOPER_PROMPT` 정확 일치 테스트
  - `build_developer_message()` 구조 테스트
