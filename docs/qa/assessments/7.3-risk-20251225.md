# Risk Profile - Story 7.3 (2025-12-25)

## 전체 판단

- **리스크 수준**: 낮음(Low)
- 이유: 이번 Story는 “운영 문서(runbook) 작성”이 중심이고, 핵심 안전장치(Story 7.1/7.2)는 이미 코드/테스트로 고정되어 있습니다. 전체 테스트 384개가 통과했습니다.

## 주요 리스크와 확인 결과

1. **OPS-001: GlobalMode를 너무 빨리 PROD로 바꿔서 전체 자동 발송이 시작되는 위험**
   - 상황: GlobalMode는 전역 스위치라서 영향 범위가 큽니다.
   - 확인: Runbook에서 “부분 PROD(채널만 PROD) → 마지막에 Global PROD” 순서를 강조하고, Global PROD 전환 단계에 경고 문구가 있습니다.
   - 제안: GlobalMode 변경 전 체크리스트(시범 채널/threshold/알림/Sheets)를 반드시 2번 확인하세요.

2. **OPS-002: echo 이벤트로 무한 루프가 생기는 위험**
   - 확인: Runbook에 echo 이벤트가 루프 위험이라는 설명이 있고, Ingest는 non-send 이벤트를 200 OK로 무시한다는 전제가 포함되어 있습니다.
   - 제안: 운영(파트너센터)에서도 echo 이벤트가 비활성 상태인지 1번 확인하세요.

3. **OPS-003: 문제 발생 시 롤백을 늦게 해서 피해가 커지는 위험**
   - 확인: Runbook에 롤백 레벨 2단계(전체 Kill Switch / 특정 채널 중단)가 있고, 즉시 적용됨을 설명합니다.
   - 제안: Go-Live 당일에는 “롤백 담당자/연락망/권한(aws cli)”을 미리 준비하세요.
