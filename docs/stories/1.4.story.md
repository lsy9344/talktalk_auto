# Story 1.4: TEST/PROD 모드 + 자동 발송 게이트(결정 로직) (Core Mode & Send Decision Rules)

## Status

## Story

**As a** 시스템 운영자(프로젝트 오너),
**I want** TEST/PROD 모드와 “자동 발송 가능/불가” 결정 규칙을 코드로 명확히 만들고,
**so that** TEST에서는 절대 고객에게 보내지 않고, PROD에서도 안전 조건을 모두 통과할 때만 보내도록 할 수 있다.

## Acceptance Criteria

1. “3단계 게이트(전역 모드 → 채널 모드 → LLM 승인)” 결정 규칙이 구현되어 있다. [Source: docs/architecture.md#test-vs-prod-mode-behavior]
2. TEST 모드에서는 어떤 경우에도 `send_to_user=false`가 되며, `action="LOG_AND_ALERT"`가 된다. [Source: docs/architecture.md#test-mode-default]
3. PROD 모드에서 자동 발송은 아래 조건을 모두 만족할 때만 `send_to_user=true`가 된다:
   - GlobalMode = `PROD`
   - ChannelConfig.channel_mode = `PROD`
   - LLM 결과가 `send_to_user=true`
   - `risk_level != "HIGH"`
   - `confidence >= channel.confidence_threshold` [Source: docs/architecture.md#prod-mode-three-gate-system]
4. 게이트가 하나라도 실패하면 `send_to_user=false`이고, `action="LOG_AND_ALERT"`가 된다. (성공 시 `action="SEND_LOG_NO_ALERT"`) [Source: docs/architecture.md#decision-logic-implementation]
5. GlobalMode를 읽는 `GlobalModeRepository.get_mode()`가 있고, DynamoDB GlobalMode 테이블(키: `config_key="GLOBAL_MODE"`)에서 `mode`를 읽는다. 값이 없으면 안전하게 `TEST`로 취급한다. [Source: docs/architecture.md#globalmode-전역-모드]
6. 위 로직은 유닛 테스트로 확인된다(최소: TEST 모드, 채널 TEST/PROD, HIGH_RISK, LOW_CONFIDENCE, LLM_DECLINED, ALL_GATES_PASSED). [Source: docs/architecture/coding-standards.md#test-strategy-and-standards]

### 핵심 규칙(쉬운 말로)

[Source: docs/architecture.md#test-vs-prod-mode-behavior]
[Source: docs/architecture.md#testprod-mode-framework]

- **TEST 모드**: 절대 고객에게 보내지 않습니다. (항상 무응답) 대신 “기록 + 알림”을 합니다.
- **PROD 모드**: 아래 3가지가 모두 “OK”일 때만 고객에게 보냅니다.
  1) 전역 모드(GlobalMode)가 PROD  
  2) 채널 모드(ChannelConfig.channel_mode)가 PROD  
  3) LLM이 보내도 된다고 승인(send_to_user=true) + 위험도 HIGH 아님 + confidence 충분

### 결정 로직 pseudo-code (참고)

[Source: docs/architecture.md#decision-logic-implementation]

- Gate 1: `global_mode != "PROD"` → no-send
- Gate 2: `channel_mode != "PROD"` → no-send
- Gate 3: `risk_level == "HIGH"` 또는 `confidence < threshold` 또는 `send_to_user == false` → no-send
- 모두 통과 → send

### LLM 결과(입력)에서 필요한 값

[Source: docs/architecture.md#decision-logic-implementation]

- `llm_response["send_to_user"]`: bool (보내도 되는지)
- `llm_response["confidence"]`: number (0~1)
- `llm_response["risk_level"]`: `"LOW" | "MEDIUM" | "HIGH"`

### 데이터 모델(이번 Story에서 쓰는 것만)

[Source: docs/architecture.md#channelconfig-채널-설정]
[Source: docs/architecture.md#globalmode-전역-모드]

- ChannelConfig에서 필요한 값:
  - `channel_mode`: `"TEST" | "PROD" | "DISABLED"`
  - `confidence_threshold`: 숫자(기본 0.80)
- GlobalMode에서 필요한 값:
  - PK: `config_key="GLOBAL_MODE"`
  - `mode`: `"TEST" | "PROD"`
