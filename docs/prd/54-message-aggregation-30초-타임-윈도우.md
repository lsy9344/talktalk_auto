# 5.4 Message Aggregation (30초 타임 윈도우)

## 배경

고객이 하나의 질문을 여러 개의 메시지로 나눠 보내는 경우가 있습니다.

그래서 같은 고객의 메시지를 잠깐(30초) 모아서, **1개의 질문**으로 만든 뒤 처리합니다.

## 요구사항(요약)

1. **수집 기준**
   * 같은 `channel_id + user_id`
   * 첫 메시지부터 30초 동안 수집
   * 최대 10개까지 수집(과도한 요청 방지)

2. **집계 완료 조건**
   * 30초 타이머 만료
   * 이미지/파일 메시지는 즉시 종료(조합 불가)
   * (Phase 2) 종료 표현 감지 시("문의드립니다", "이상입니다" 등)

3. **메시지 조합 방식**
   * 시간순 정렬
   * 줄바꿈(`\n`)으로 연결
   * 최종 문의 텍스트는 500자 이하(넘으면 뒤에서 500자만 사용)

4. **처리 방식**
   * 조합된 텍스트로 기존 RAG + LLM 파이프라인 실행
   * 응답은 최대 30초 지연될 수 있음
